# AI Contributions & Safety Policy 🤖🔒

## Overview

The `elevate-privilege` workspace provides critical system-level authentication, privilege escalation, and user management capabilities. Due to the high-security nature of authentication software, this **Strict AI Policy** governs the generation, auditing, and acceptance of any AI-assisted code contributions within this repository.

---

## 🛡️ Core Directives

### 1. Mandatory Human Oversight & Engineering Review
- **No Unreviewed AI Code**: No code, modification, or security patch generated by AI language models may be merged or deployed to production without rigorous human systems engineering review.
- **Verification Requirement**: All AI-assisted changes must be verified for functional correctness, boundary safety, and memory integrity.

### 2. Memory Safety Non-Negotiable (`#![deny(unsafe_code)]`)
- **Unsafe Code Prohibition**: AI tools are strictly forbidden from introducing `unsafe` code blocks, raw pointer dereferences, or memory-unsafe operations into core authentication paths.
- **Rust Safety Standards**: All code must adhere to pure, memory-safe Rust standards.

### 3. Strict Cryptographic & Authentication Integrity
- **No Weak Hashing Fallbacks**: AI tools must never weaken cryptographic algorithms. Password hashing must strictly use **Argon2id**, and integrity checks must use **Blake3** and **Ed25519**.
- **No Security Bypass**: AI suggestions must never introduce backdoors, privilege bypasses, or telemetry that logs user credentials, password hashes, or private keys.

### 4. Zero Supply-Chain Contamination
- **Dependency Guard**: AI tools must not add unvetted third-party crates or external C dependencies to the workspace.
- **Standalone Guarantee**: All authentication modules must remain internal to the consolidated `elevate-privilege` workspace.

### 5. Privacy & Data Confidentiality
- **No Sensitive Leakage**: Developers using AI coding assistants must ensure that production configuration files, system user entries, and cryptographic private keys are never transmitted to external AI model endpoints.

---

## ⚖️ Policy Enforcement

Violations of this AI safety policy will result in immediate rejection of pull requests and audit remediation.
